# 🌹 Jardín Encantado de Luna — Versión 2.0

Experiencia web interactiva de cumpleaños creada con HTML, CSS, SVG, Canvas y JavaScript puro.

## Ejecutar localmente

No abra el archivo con doble clic si el navegador bloquea recursos. Use uno de estos métodos:

### VS Code
Instale la extensión **Live Server**, abra `index.html` y seleccione **Open with Live Server**.

### Python
```bash
python -m http.server 5500
```
Luego visite `http://localhost:5500`.

## Publicar en GitHub Pages
1. Suba los archivos al repositorio.
2. Abra **Settings → Pages**.
3. Seleccione **Deploy from a branch**.
4. Elija la rama `main` y la carpeta `/root`.

## Estructura
- `index.html`: pantallas y contenido.
- `style.css`: jardín, rosas, carta y diseño adaptable.
- `script.js`: interacción, música, partículas y flujo narrativo.
- `assets/music/up.mp3`: música de fondo.
- `AGENTS.md`: instrucciones para Codex en VS Code.

## Personalización
Las frases están en `MESSAGES` y la carta en `LETTER`, al comienzo de `script.js`.
